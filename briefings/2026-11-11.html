1. Homesage.ai launches return-first property search — find rentals by the yield, not the bedroom count

Nov 10, EIN Presswire (vendor release) | einpresswire.com/article/954814214/homesage-ai-launches-ai-that-finds-and-analyzes-rental-properties

  • What it is: Homesage.ai (Washington, DC) launched Investment Property Search: instead of searching listings by price, beds, and baths, a rental-investment company sets a target cap rate (the property's yearly return as a share of its price) or cash-on-cash return (yearly cash profit as a share of the cash put in), and the search returns for-sale homes that meet it, each with an estimated monthly rent attached. It runs on the company's database of 160M+ US properties (vendor figure), and the same data is reachable by AI agents through Homesage's MCP server (the connector that lets an assistant like Claude or ChatGPT call outside tools). Plans run on credits; every self-serve plan starts with a 30-day trial.
  • What it means: this is the investor side of the "around the gate" data layer from briefing #1 — public-records and modeled property data, sold as search-by-return rather than search-by-listing, with no MLS credentialing in the loop. The product read: the return is the search key, which is a genuinely different query shape from every portal's price/beds/baths filter — and the MCP server means an agent can underwrite a deal in one conversation (resolve address, grade condition, price the work, project the return). For Jessica, the angle is the mirror image: Homesage sells the investor's question; nobody in this record sells the agent's version — "which of my listings pencils as a rental, and for which of my buyers?" — wired into an MLS or IDX feed. Flag: vendor release only; no independent test, no user numbers, no pricing beyond credit-based. The 160M+ figure is the company's own; the MCP server itself launched earlier (July/Nov 3 releases) — only the Investment Property Search is new today.

2. Brokurz lets outside AI agents into the CRM — Grok Bot, Dots, and Muse can read lead briefs

Nov 7, BotRadar (launch radar; catch-up — missed by #24/#25) | botradar.ai/radar/

  • What it is: Brokurz AI Assistants adds a built-in assistant ("Kurz") to the Brokurz real-estate CRM, and — the newer part — lets outside assistants such as Grok Bot, Dots, or Muse read lead briefs, save notes, draft texts, and create follow-up tasks inside the CRM, under permissions the user sets. Connecting one does not send texts on its own. It is for agents, teams, and brokerages already using Brokurz.
  • What it means: this is the CRM opening its door to the agent layer instead of building its own assistant — the same distribution question as BoldTrail's MCP (briefing #1) and Flexmls Scout (#25), but from the small-vendor side: the CRM becomes the place where your agent works, not the vendor's. The permissioned-read shape matters — the assistant can read and draft but not act unprompted — which is the same "human gate between chains" design rule from the Dots safety number in Topic 1. For the reverse-engineering lens: the interesting question is what the permission model actually allows (which fields, which actions, what audit trail), because that is the spec any competing CRM integration would have to match. Flag: single source, a launch-radar listing — no vendor release, pricing, or user count surfaced in-window; treat as a lead, not a verified launch.

Whitespace

The listing-rights ledger — now a multi-jurisdiction market. Briefings #25–#26 framed the compliance tool as a Jan 1, 2027 deadline play (California + Wisconsin photo-disclosure laws). Two new data points widen it: North Texas's NTREIS renamed compliance "Data Quality" on Nov 1 and now requires AI-altered photos to be disclosed with the unstaged version included — fines begin Feb 1, 2027 — and Ontario's regulator RECO issued AI guidance Nov 5 requiring disclosure when AI materially shapes a listing or ad, with the agent liable for accuracy. The tool that archives the original, stamps the edit, writes the disclosure, and records who owns each asset (broker, photographer, or MLS under NAR's new 50% provision) now has buyers in at least four jurisdictions, not two — and each new regulator that writes its own wording is another market, not another competitor. Nobody in this record sells that combined check.
